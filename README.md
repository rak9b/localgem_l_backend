## 1. Project Overview
Express.js & Prisma engine for the LocalGems ecosystem.

## 2. Features
- **RBAC**: Multi-role authorization middleware.
- **Transactions**: Atomic database updates via Prisma.

## 3. Architecture
Modular clean architecture with separate Service and Controller layers.

## 4. Technology Stack
Node.js, Express, Prisma, PostgreSQL, JWT.

## 5. Security Considerations
- **Helmet**: Secure headers.
- **Rate-Limit**: 100 reqs/15min on Auth.
- **Hashing**: Bcrypt Salt 12.

## 6. Monitoring & Logging
- **Winston**: Console and File logging.
- **Health**: `/api/v1/health` endpoint.

## 7. Database Management
- **Prisma Migrate** for schema versioning.
- **PostgreSQL** relational integrity.
